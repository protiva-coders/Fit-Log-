# FitLog

FitLog is a responsive workout library and workout planning web application built with Next.js. Users can browse workouts, view workout details, add workouts to today's plan, save workouts for later, and manage their workout plan.

## Live Site

https://fit-log-seven-mu.vercel.app/

## GitHub Repository

https://github.com/protiva-coders/Fit-Log-.git

## Technologies Used

- Next.js
- React
- TypeScript
- Tailwind CSS
- React Toastify
- REST API
- LocalStorage

## Features

- Responsive workout library for mobile, tablet, and desktop
- Browse workouts with category, difficulty, equipment, duration, calories, and rating
- View detailed information for each workout
- Add workouts to Today's Plan
- Save workouts for later
- Prevent duplicate workouts in the plan and saved list
- Manage workouts from the My Plan page
- Mark workouts as completed
- Remove workouts from the plan
- Sort workouts by duration, calories, or rating
- Loading and empty states
- Custom 404 page
- Toast notifications for user actions
- Workout and saved data stored using LocalStorage
